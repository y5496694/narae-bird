사이트 주소와 소개를 관리하고, Termux 웹·데이터 서버를 연결하세요.

관리자 로그인

도메인 관리와 나래 버드는 같은 관리자 계정·로그인을 사용합니다.

로그인은 이 기기에서 30일 동안 유지됩니다. 공용 기기에서는 로그아웃하세요.

내 사이트

주소는 현재 도메인/이름 형태입니다. DNS 하위 도메인과는 다릅니다. 기존 운영 주소는 보호됩니다.

사이트 만들기

소개 페이지 내용은 텍스트로 안전하게 표시됩니다. Termux 연결은 HTTP 웹/API를 지원하며 요청은 16MB까지입니다. 관리 계정 보호를 위해 연결 사이트는 브라우저 격리 정책을 적용합니다.

Termux 연결

외부 접속용 포트를 열지 않아도 됩니다. 휴대폰에서 커넥터를 실행한 후 사이트 형식을 선택하세요.

pkg install python
pip install websocket-client
curl -fsS https://aiedue.ddns.net/domain/bird.py -o bird.py
python bird.py login
python bird.py connect --port 8080 --label 내폰

8080은 Termux에서 실제로 실행 중인 웹 서버 포트로 바꾸세요. 커넥터만으로 웹 서버가 만들어지는 것은 아닙니다. termux-wake-lock과 배터리 최적화 제외를 권장합니다.

기존 운영 주소 열람

보낼 파일 등록

파일을 등록하고 이 화면을 열어 두세요. 같은 계정으로 로그인한 다른 기기에서 수신을 선택하면 전송됩니다.

서버 디스크에 저장하지 않는 실시간 중계입니다. 송신 탭을 닫거나 기기 연결이 끊기면 받을 수 없습니다. 등록은 30분 후 만료되며, 완료된 목록은 잠시 뒤 사라집니다.

내 계정의 송신·수신 목록

Termux / GPT에서 사용하기
python bird.py login
python bird.py send ./파일.zip
python bird.py list
python bird.py receive 전송ID --out ./받은파일.zip

송신 명령은 수신자가 선택할 때까지 실행 상태를 유지합니다. 다른 기기도 같은 계정으로 로그인해야 합니다. 비밀번호·세션은 명령 인자나 URL에 넣지 않습니다.
